What these charts answer

Every point is one report, scored on the whole record up to that day: standing in a dry hour, did anything warn that rain would start within three hours? Rain already falling is excluded, so a model that merely recognises wet weather earns nothing here.

Skill — front AUC

0.5 is a coin toss; the dashed line marks it. A series that hugs that line has no ability to anticipate rain, however well it scores on other targets.

Is it aiming, or just yelling? — lift over random

How many rain starts the model caught, divided by how many the same number of alert-hours would catch scattered at random. At or below 1.0 the alerts carry no information.

What it costs — alert-hours per week

Hours a week the alert would be raised at the threshold each model is scored at. This is the number a person actually pays.
